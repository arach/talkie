# Round 3 — The current deck, adapted for iPad

## Goal

Produce credible iPad arrangements of the command deck that already ships in Talkie, then apply bounded operational-polish passes to the favored arrangement. This is an adaptation exercise, not a new product concept.

## Incumbent contract

- Preserve the black instrument chassis, amber signal color, warm-white text, raised command keys, and compact monospaced telemetry.
- Preserve the six numbered lanes, exact-task console, `STEER` / `QUEUE` delivery modes, 4×4 command vocabulary, and hold-to-talk control. `STEER`, `TASK`, `MAPPER`, and `QUEUE` are canonical agentic terms and must retain both their names and meanings.
- Preserve truthful task states: `RDY`, `RUN`, `QUE`, `RX`, and `ERR`. Do not invent percentages, ETAs, queue positions, or fake system telemetry.
- Keep voice as the fastest path to action. The iPad is a remote command surface, not an IDE.

## Six bounded takes

1. **Direct scale** — the incumbent console-over-keybed hierarchy opened to the iPad width.
2. **Calmer margins** — the same proportions in a quieter 900-point instrument column.
3. **More console** — the same stack and 4×4 keybed with a modest reading-space bias.
4. **Operational polish** — Take 03 kept intact, with truthful per-lane state exposed and the small delivery and recovery controls brought to 44-point touch targets.
5. **Live dock** — the ceremonial app header is removed; `THREAD`, `DETAILS`, `HISTORY`, and host state occupy the console utility rail; live status, direction entry, and `STEER` / `QUEUE` own the lower dock; the remaining commands reflow to a 5×3 field with a wider TALK key.
6. **Console ledger** — the header stays removed; the exact-task console shares its body with a permanent, compact `DETAILS` and `HISTORY` ledger; live direction remains docked to the task; the remaining commands form a balanced 4×3 field above a full-width TALK plinth.

## Evaluation rubric

1. Incumbent fidelity — recognizably the same Talkie deck at first glance.
2. iPad value — extra width materially improves reading or reach.
3. Exact-task clarity — the active lane, host, status, and delivery mode remain obvious.
4. Hierarchy and legibility — no new chrome competes with the task.
5. Restraint and craft — spacing, type, depth, and states feel deliberate.

## Render and iteration budget

- Render all takes at the iPad Air landscape point geometry: **1180 × 820**.
- One implementation round, followed by one visual polish pass.
- Use the same example task and state across every take so the layout is the only variable.
