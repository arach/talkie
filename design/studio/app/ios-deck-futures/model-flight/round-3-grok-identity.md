**Role:** Conceptual distinction and Talkie identity editor  
**Inputs:** three briefs; Round 1 (Grok, Kimi, Opus); Round 2 (Grok→Opus, Kimi→Grok, Opus→Kimi)  
**Mode:** Composition only. No application code.

---

## 1. Binding lenses

| Lens | Pass | Fail |
|---|---|---|
| Not enlarged iPhone | Dominant work surface + one task switcher + one Talk edge | Keybed, lane ribbon, equal setup keys, `NO LANE` error |
| Not generic dashboard | One navy focal surface; evidence subordinate | Equal widget panes; swimlane ops canvas; Gantt/trace reading |
| Restrained instrument | Porcelain chassis, navy work, cobalt live/select only; one attention + one failure signal; plain state | Terminal theater, rainbow status, codes as sole meaning |
| Useful boldness | Pin Needs you; latest truth largest; freeze record on Mac failure | Color-only attention; empty idle navy; quiet failure banner alone |
| Truthful Needs you / Mac | Controls and state from verified or labeled-proposed data; voice never approves; selection locks during capture | Drawn turn Stop; false Idle; answer-by-voice on non-selected question |

**Promise:** See the work. Hear what came back. Speak the next move.

## 2. Rank

| Rank | Structure | Verdict |
|---:|---|---|
| **1** | **Fixed Command Desk** (revised) | **Lead · production** |
| 2 | Operational Folio (revised) | Alternate · reading-first |
| 3 | Selected-Task Tape | Conditional instrument |
| 4 | Cross-Task Chronicle | Components only · not primary |

| Structure | Why |
|---|---|
| Desk | Lowest data tax; fixed Talk; four first-glance answers on verified objects; portrait keeps identity |
| Folio | Best long-result reading if Talk is page-invariant and default split unequal (≥520 Task / ≤396 Record) |
| Tape | Best sticky attention + terminal failure ideas; primary only if event/update stream beats conversation |
| Chronicle | Dashboard gravity, dual select/inspect, landscape-only, multi-task event tax |

Cross-round adversarial consensus: Desk ships; Chronicle demotes; Tape/Folio donate mechanisms.

## 3. Production composition — Talkie Task Desk

### Topology

| Zone | Intent | Role |
|---|---|---|
| Work rail | ~24% chassis | Quiet Mac health; named tasks; recency or verified state; Browse tasks |
| Live work | remaining navy | Selected truth + sticky Needs you + exchange + Hear/Copy |
| Voice shelf | bottom of live work only | Hold Talk; destination name inside control; consequence helper |
| Evidence | on demand | History / turn depth; third column only if ≥2 modules have real content |

**Default: two columns.** Third column only when content earns it, and navy still wins by ≥120 pt. Never reserve empty evidence width.

### Fixed rules

- Idle / Working / Needs you share frames; only content changes.
- Mac unavailable: full-width failure band + stale treatment; no column thrash.
- One selection model: rail tap. No lane ribbon / prev-next. Unmapped: omit lane.
- **Selection locks from capture start until send or cancel.**

### Focal content

| State | Live work holds |
|---|---|
| Idle | Instruction + result (or honest “no result yet”) |
| Working | Instruction + plain Working or verified activity |
| Needs you | Blocking fact/question pinned above exchange |
| Mac unavailable | Stale last-known + recovery |

### Voice helpers

| Condition | Helper | Talk |
|---|---|---|
| No active turn | Hold to continue this task | On |
| Active, Steer | Hold to steer this turn | On |
| Active, Queue | Hold to queue a follow-up | On |
| Needs you, text OK | Hold to answer | On |
| Mac unavailable | Talk unavailable while the Mac is offline | Off |

Voice never Approve / Deny / Stop / mode change.

### Attention and failure (required boldness)

1. Unresolved Needs you pins on live surface until resolved; honest label if chronology is suspended.
2. Rail keeps durable attention; Needs you outranks Working.
3. Other task needs you → rail mark (+ optional strip). Never primary question above Talk bound elsewhere.
4. Mac unavailable: name Mac, last successful contact, Reconnect / Review / Choose another Mac; stale caption; Talk off with reason.

### Portrait / compact

Live work + Talk primary. Rail → switcher. Evidence → drawer/sheet. Collapse evidence first. Never orphan Talk on a second page. Never reduce names to lane numbers.

## 4. Compatible adoptions

| From | Feature | How |
|---|---|---|
| Tape / R2 | Sticky Needs you + honest pin | Live-surface pin |
| Tape | Terminal failure honesty | Failure band + last-known / last successful contact |
| Tape | In-turn updates (if dense) | Inline under Working — not full timeline chrome |
| Folio | Long-result reading weight | Read full / optional column when earned |
| Folio | Single-open focus | Sheet or temporary expand only |
| Chronicle | Rail Needs you promotion | Sort/group attention above recency |
| Chronicle | Multi-Mac freeze | Only if multiple Macs |
| All | Destination inside Talk; no `NO LANE` error | Mandatory |

## 5. Must not combine

| Forbidden | Why |
|---|---|
| Folio focus + Chronicle swimlanes | Window management |
| Dual highlight (select vs inspect) on primary | Voice mis-target |
| Event tap / empty-lane retargets Talk | One explicit rail (or “Talk to this task”) gesture |
| ~50/50 Task/Record default | Loses instrument hierarchy |
| Permanent empty third column | Admin dashboard |
| Chronicle time axis as primary | Ops monitor, not Talkie |
| Talk only on one portrait pager page | Breaks Talk primacy |
| Turn Stop button / invented Approve as shipped | Capability lie |
| Idle/Working on every row without first-hand evidence | False calm |
| Changed files / checkpoints justifying geometry | Unconfirmed |

## 6. Current vs proposed data

### Current (design free)

Task name, project, branch/path, Mac · optional lane · latest instruction/result/history turns with timestamps · Working activity when dispatched · Steer/Queue · last successful contact · History/Details/Readout destinations · hold Talk mechanics.

### Proposed / partial (label until verified)

| Item | Constraint |
|---|---|
| Durable Needs you on every rail row | Job `blocked` exists; passive catalog attribute is store work |
| State for tasks this device never touched | Prefer recency (`updatedAt`) or Unknown — not false Idle |
| Always-on activity prose | Degrade to plain Working |
| Deck catalog refresh always running | Required for persistent rail |
| Live elapsed ticker | Derive if start time exists |
| Affirmative Mac unavailable | Inferred from failed contact + last success; copy must not overclaim |
| iPad approval actions | May be “Open in Codex Desktop”; labels proposed |
| Turn Stop from iPad | **Unsupported — do not draw** |
| All-task event streams | Not required for primary |
| Files / checkpoints / tokens / traces | Out of scope |

---

## 7. Five visual acceptance checks

1. **Idle landscape:** selected task, Mac, state or recency, latest result, `Hold to continue this task` with destination — no sheet, no keybed, no empty navy.  
2. **Hierarchy:** one navy instrument face; chassis rail/evidence; cobalt only for selection/live; no rainbow status.  
3. **Needs you:** pin readable without color alone; rail still marks after switch; `Hold to answer` only when selected task owns the question.  
4. **Mac unavailable:** names Mac + last successful contact; stale last-known; Talk off with reason; recovery visible.  
5. **Portrait/compact:** task, state/recency, latest truth, and Talk remain primary; Talk not page-orphaned; names not lane numbers.

---

## 8. Decision

**Ship revised Fixed Command Desk (Talkie Task Desk): two-column default, evidence on demand, sticky Needs you, terminal-honest failure, fixed Talk with destination inside the control. Adopt only the compatible features above. Do not ship Chronicle as primary. Gate full Tape chrome on real event density.**
